2. Descripción actualizada del proyecto 
RiskMetrics Studio es una propuesta de análisis de datos que utiliza herramientas de 
probabilidad, estadística y programación en Python para organizar información, identificar 
patrones y detectar posibles anomalías en conjuntos de datos. La versión inicial estaba 
orientada principalmente al análisis de riesgos y desastres naturales. En esta actualización se 
amplía el alcance mediante un caso de estudio relacionado con datos electorales, demostrando 
que las mismas técnicas pueden utilizarse para revisar información pública de manera 
sistemática. 
3. Problemática y justificación 
En proyectos basados en datos, grandes cantidades de información pueden dificultar la 
identificación de patrones, diferencias o valores atípicos cuando se realiza una revisión manual. 
Por ello, el proyecto propone una herramienta que permita cargar datos, limpiarlos, resumirlos 
mediante estadística descriptiva, representarlos gráficamente y señalar comportamientos que 
requieran una revisión posterior. 
4. Objetivo general actualizado 
Desarrollar un prototipo de análisis estadístico en Python capaz de procesar datos históricos, 
generar indicadores y gráficos, y señalar posibles anomalías en conjuntos de datos 
relacionados con riesgos y, como caso complementario, resultados electorales. 
5. Objetivos específicos 
• Recolectar y organizar datos provenientes de fuentes públicas y verificables. 
• Aplicar medidas de tendencia central, dispersión, frecuencia y probabilidad. 
• Representar resultados mediante tablas y gráficos. 
• Comparar registros o periodos cuando existan dos fuentes de datos compatibles. 
• Identificar valores o cambios que se aparten de los patrones esperados. 
• Documentar criterios para evitar conclusiones apresuradas. 
• Desarrollar una interfaz sencilla para visualizar resultados. 
• Preparar el informe final y la demostración del prototipo.

9. Metodología propuesta 
1. Recolección: Obtener datos públicos y documentar su origen. 
2. Limpieza: Revisar valores faltantes, duplicados, formatos y consistencia. 
3. Exploración: Calcular frecuencias, media, mediana, moda, rango y medidas de dispersión. 
4. Comparación: Contrastar registros compatibles y calcular diferencias.

10. Alcance y limitaciones 
El prototipo tendrá un propósito académico y demostrativo. No sustituirá auditorías 
electorales, peritajes informáticos ni decisiones de autoridades electorales o judiciales. Una 
diferencia estadística puede tener explicaciones administrativas, errores de digitación, 
correcciones legítimas o problemas de calidad de datos. Por ello, el sistema mostrará 
indicadores reproducibles y casos que merecen revisión, pero no emitirá acusaciones.
